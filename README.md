# Jonathan Otiniel — Portfólio V3

Portfólio pessoal com direção visual editorial cinematográfica, superfícies em carvão, azul concentrado, tipografia expressiva e movimento em CSS.

## Tecnologias
- React 19
- TypeScript / TSX
- Vite 8
- CSS e Tailwind CSS v4

## Rodar localmente
Requer Node.js 20.19+ ou 22.12+.

```bash
npm install
npm run dev
```

## Build de produção
```bash
npm run build
npm run preview
```

A saída estática é gerada em `dist/`.

## Publicação
Configurado para publicação no Render como Static Site: build `npm install --no-audit --no-fund && npm run build`, diretório publicado `dist`.

## Estrutura
- `src/App.tsx`: navegação, páginas e seções.
- `src/data/`: informações do portfólio e projetos.
- `src/components/`: componentes compartilhados e movimento.
- `src/index.css` e `src/cinematic.css`: sistema visual e direção cinematográfica.
- `docs/design-system.md`: documentação visual.

Informações não confirmadas não são apresentadas como fatos. O currículo PDF e os canais de contato permanecem pendentes dos dados reais.
